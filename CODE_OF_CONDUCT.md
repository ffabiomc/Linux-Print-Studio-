# Community code of conduct / Código de conduta

Treat contributors respectfully. Welcome constructive disagreement, avoid harassment, discrimination, threats and disclosure of private information. Keep discussions focused on the project. Report abusive behavior privately through the repository owner's available contact channels or GitHub reporting tools. Do not post sensitive evidence publicly. Maintainers may remove abusive content or restrict participation proportionately.

Respeite os participantes, aceite divergências construtivas e não pratique assédio, discriminação, ameaças ou exposição de dados privados. Mantenha discussões focadas no projeto. Denuncie abusos pelos canais privados disponíveis ou pelas ferramentas do GitHub. A moderação poderá remover conteúdo abusivo ou restringir a participação de forma proporcional.
