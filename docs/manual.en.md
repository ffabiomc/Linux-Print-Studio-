# Linux Print Studio user manual

[Installation](../INSTALL.md) · [Português](manual.pt_BR.md)

## Getting started
Install the native package for your distribution and launch Linux Print Studio from the application menu. Never run the GUI as root.

## Printing a PDF
Open or drag a local PDF into the window. Select a physical printer, paper size, orientation and copies. Select all, odd, even or custom pages (for example 1-5, 8, 12-15). Review the preview before printing.

## Layout and PDF export
Choose normal, booklet or 2, 4, 6, 9 or 16 pages per sheet. Booklet layout reorders pages for folding and may insert blanks. Export PDF to save the imposed document without printing. Adjust scaling, margins, centering, color and quality; actual printer support depends on its driver.

## Duplex
For automatic duplex, choose long-edge or short-edge binding. For manual duplex, select the printer, use calibration sheets, save the correct feed orientation, print fronts, wait for completion, reload as instructed and confirm printing backs. Test a few sheets first.

## Preferences
Save defaults and named profiles for recurring jobs. Select system, light or dark theme and language in general settings. Restart after changing language. Resetting printing defaults preserves named profiles and calibration.

## Virtual printer
Install the virtual queue through its management interface with administrator authorization. Select Linux Print Studio in another application's print dialog. The user receiver should open the PDF in the GUI. Try the system print dialog if the browser does not show the queue. RAW compatibility varies.

## Troubleshooting
See [virtual printer guide](virtual-printer.md). Report distribution, desktop environment, build, printer model and reproduction steps. Remove confidential documents and personal information from logs.

## Limitations
Physical printer compatibility, Arabic RTL and desktop integration require further manual validation. This guide describes implemented features, not universal compatibility. Screenshots are pending.
